# 准确路由隔离与唯一开发协作例外

默认跨项目拒绝；现场核source/target project、固定task/title/cwd/分组及payload/hash，注册表描述不能当许可。注册角色数量动态，旧六/十一/十三不构成准入。

指定开发仅取registry.collaboration_bindings.designated-development的准确原聊天；新goal冻结authorized_scope/approved_actions和实际target_live_proof全部匹配才可走此人类批准例外，不扩大到其他网站、Vendure、购物、CloudBridge或ID。历史例外许可不通用于新任务。

误路由只保存准确实际原因，停止该目标动作，原任务其他独立工作继续；合法恢复核原身份/实际健康/当前scope与既有工具，prepared不算sent，不造旧policy通过或新聊天。总部不用持续守候，负责助理按原完整目标接续；普通active消息排队。自动任务目标只原生有权者更新，开发不手改平台。
