## 1. 官方事实（2026-10-09访问）

- Google 2025-10-13公告明确：每个Sponsored results文字广告分组最多4条；页底及AI Overview上/下可有分组。这不是整页统一最多4条，也不是购物、地图等所有广告形式的上限。竞争者5家不等于每天固定淘汰同一家。[Google正式公告](https://blog.google/products/ads-commerce/google-search-sponsored-results-label/)
- 每次搜索、各位置分别竞价；Ad Rank决定资格及相对位置，取决于出价、当次广告/落地页质量、门槛、竞争、搜索环境和素材。没人显示也可能存在最低Ad Rank门槛；竞品不展示不等于无人参与。[Ad Rank](https://support.google.com/google-ads/answer/1722122?hl=en)
- 现行顶部/绝对顶部指标不是完整的第几名序号；顶部但非第一包括第二及以后，不能证明第二/第三或排除第四。[顶部指标](https://support.google.com/google-ads/answer/7501826?hl=en)
- Target impression share只有Top / Absolute top / Anywhere方向，没有保证第二/第三的开关，也不保证达到指定份额。现阶段不自动切换策略。[目标展示份额](https://support.google.com/google-ads/answer/9121108?hl=en)
- 质量得分及三项分量用于诊断；账户展示的1–10质量分本身不是竞价输入，不能套“出价×质量分”计算真实排名。[质量分](https://support.google.com/google-ads/answer/6167118?hl=en)
- 展示/点击/花费和竞争指标不是同一刷新速度。竞争指标通常按日更新且官方时间表可能滞后多日；份额/质量分不足也可能显示“—”。不要把4小时未刷新当成调价失败。[数据新鲜度](https://support.google.com/google-ads/answer/2544985?hl=en)、[展示份额](https://support.google.com/google-ads/answer/2497703?hl=en)
- Auction insights受活动量门槛限制，当前说明还写展示份额低于10%时不提供；空报表不能证明零竞争。看到的是参与相同竞价的可见竞争者，不是全市场总人数。[竞价分析](https://support.google.com/google-ads/answer/2579754?hl=en)

## 2. 每词记录合同

主键：账户＋campaign ID＋adgroup ID＋Exact文本/匹配＋平台criterion ID（可安全读出时）；无数值ID不编造。一个词一个记录，不借同类词的数据冒充。

每个字段附数据日期窗、抓取时间、来源、粒度、更新时间/延迟及已执行/候选状态：

| 范围 | 必须记录 |
|---|---|
| 当前基础与有效竞价上限 | 当前最高CPC、广告组默认/关键词覆盖、设备/地域/排期/受众等有效调整 |
| 能否展示 | Enabled和资格、审核/低搜索量/否词冲突、日期时段、地域/网络、网址 |
| 实际触达与费用 | 展示、点击、花费、CTR、实际平均CPC；有无分母分别处理 |
| 展示机会与丢失原因 | Search IS、Search top IS、可用的rank lost IS/top IS；budget lost IS仅使用账户实际支持粒度，不能把系列值拆成各词值 |
| 展示位置观察 | Impr.(Top)%、Impr.(Abs.Top)%、指定设备/地域/语言/时间的合法原生预览诊断；单次预览只是快照 |
| 竞价与质量 | 原生首页/页首估算（不是保证价）、Auction insights、质量分三项诊断、广告/页面意图匹配 |
| 商业结果 | 主要表单成功转化；另列阿文确认有效咨询、报价/成交、有效咨询成本；TEST/内部验收排除 |
| 决策 | 保留/降价试验/加价候选/修质量/修资格/停止复核/等待数据；旧价、新价建议、依据、样本、护栏、回滚、负责人 |

读不到就记DATA_MISSING、NOT_EXPOSED、NO_ACCESS或NOT_MEASURED。零点击时平均CPC不是0；没有销售真值，不计算实际CPL/ROI。当前截图“5家参与”不能作为每词精确价格依据。

5. 报告必须给出：哪些词没展示、已证实原因、价格建议和依据、有哪些词还缺数据、实际改价几项及回读结果。四小时巡检不是实时自动止损。

## 4. 动态决策顺序

| 观测 | 动作方向 | 禁止的推断/操作 |
|---|---|---|
| 低搜索量、审核未过、日期/否词/地区/网址不符 | 先修需求/资格；缺哪个读哪个 | 不把0展示直接判成价低 |
| 资格正常且真实rank损失高、budget损失不是主因 | 先核相关性/页面/素材；可展示且有价值的词做准确小步加价候选 | 不因“5家4位”无限抬价；不越RM3当前护栏 |
| 顶部可见、成本合适、有效咨询质量可用 | 保持，或者按单变量降上限探测更低成本 | 不因偶尔第一就立即降价；不以排名冒充效果 |
| 顶部很高但无有效咨询 | 查搜索意图/承诺/页面/追踪和销售反馈，必要时复核收紧 | 不为守名次持续加价 |
| budget损失主导 | 在冻结总预算内评估浪费、重点词和时段；调整候选另锁准确范围 | 不靠提高CPC解决预算不足、不自动增预算 |
| 指标“—”、极小样本、竞争数据未刷新 | 保持待补证；保留已批准有界探測和异常检查 | 不把未知写成零竞争/第四位/最低价 |

小步策略是待验证建议，不是Google规定：正常成熟词一次拟调10%–15%，同词至少一个完整日且优先两个完整窗口再复查；低价新词按原已批准小试梯度，不在每4小时反复升降。不把这些百分比写成已经批准的全量自动调价。提高出价不保证Top rate上涨，故Top/AbsTop“率”只作诊断，不单独当调价目标；结合机会份额、丢失原因和业务质量。

若当前RM3仍达不到有价值可见性：先出该词准确证据和经济性判断，不直接超上限。如果需要越RM3或切换策略，只提出新精确范围；本方案不授予这类动作。
