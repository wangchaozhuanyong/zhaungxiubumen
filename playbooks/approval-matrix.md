# 人工审批矩阵

| 动作 | Agent 可否直接做 | 需要谁批准 |
|---|---:|---|
| 读取脱敏广告数据 | 可以 | 无 |
| 生成广告文案草稿 | 可以 | 发布前由负责人批准 |
| 建议否定关键词 | 可以 | 修改账户前由广告负责人批准 |
| 调整 Google Ads 预算 | 不可以 | 公司负责人 |
| 暂停或删除广告 | 不可以 | 公司负责人 |
| 生成 SEO 文章草稿 | 可以 | 无；发布仍需通过事实与 QA 门禁 |
| 修改装修网站代码 | 常驻授权范围内可以 | `owner-standing-flashcast-site-publish-20260906` |
| 发布装修网站内容 | QA 和发布门禁通过后可以 | `owner-standing-flashcast-site-publish-20260906`，无需逐次请示 |
| R1 常规 CMS 内容 | 可以 | QA 无 P0/范围内 P1后，由运营记录 `AUTO_RELEASE` |
| R2 低影响网站代码 | 可以 | 受影响测试、typecheck、build、QA 和回滚齐全后，由运营记录 `AUTO_RELEASE` |
| R3 高风险网站动作 | 不可以 | 公司负责人精确批准 |
| 发布购物网站或其他项目 | 不可以 | 不在装修网站常驻授权范围内 |
| 发送客户消息 | 不可以 | 销售负责人 |
| 处理合同、付款和法律承诺 | 不可以 | 专业人员/公司负责人 |
