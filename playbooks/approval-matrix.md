# 真实授权与常规接续矩阵

| 动作 | 实际责任 | 条件 |
|---|---|---|
| 内部读取/分析/准确候选 | 原专业部门 | 原goal范围、真实数据、自检；不扩外部权 |
| 完整成果独立验收/最小返工/准确关闭 | 唯一能力匹配助理 | 未参与制作、准确版本证据、真实收取与后续 |
| 已批准队列下一任务 | 负责助理 | 真实固定目标/健康/政策、实际派工回执 |
| CMS保存 | publishing | 原精确授权、事实/自检/备份CAS/受保护通道、真实回执 |
| 代码/CI/部署 | 指定开发 | 原任务准确授权、Git/PR/CI/main同SHA、备份回滚与公开复核 |
| 已直接授权付费执行 | 付费部 | 原真实授权与精确范围，不加旧QA/HQ链、不扩费用 |
| 新方向或授权外生产动作 | 总部/老板 | 具体影响/范围/合法执行者/回滚方案，单独准确授权 |
| 客户外联/付款/合同/账号/Maps | 原法定授权者 | 无默认扩权，候选或助理PASS不算许可 |

总部不二审已独立验收的范围，批准、实际执行、公众可见与业务效果分别记录。
