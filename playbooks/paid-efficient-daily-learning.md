# 付费推广每日学习与降本闭环

老板于2026-10-08明确要求：用更少的实际开支获取更好的真实推广效果，每天上网学习最新推广技术和方案，周末同样执行。本流程是付费部的R0研究与核验方法，不增加账户、生产、客户联系、跨任务或付款权限。

## 执行入口与边界

复用已存在且ACTIVE的 `flash-cast-3`，固定付费聊天<LOCAL_TASK_ID>。老板新增四小时汇报后，V42精确许可下已实际保存为每天10:00、14:00、18:00、22:00 Asia/Kuala_Lumpur，周末照常；10:00兼完整专业日检及官方降本研究，不新建第二个任务。保存回读见V42 monitor-save-semantic-verification；未来实际运行仍须逐轮核验。电脑和应用需保持可运行、项目目录可用；不能保证关机时执行。[OpenAI官方定时任务说明](https://learn.chatgpt.com/docs/automations?surface=app)

先续原任务和未完验收，再进行有界研究。固定身份/健康异常时停止依赖的动作并记录实际原因。老板直接审核的准备分支不发其他聊天；普通自动日检结果按当时有效合同入队，不改变原任务归属。日检不反复提交验收表单。

## 每日工作顺序

1. 读取准确原任务、最近真实保存/验收、未完事项及本部门经验。先区分方案、保存、Google技术验证、真实咨询和有效线索，不能重复把已完成的老问题报成未修复。
2. 核对同一账户、MYR、马来西亚时区和日期窗。明确最新完整业务日、最新来源截止日和1/7/28日覆盖缺口；缺失写DATA_MISSING，不把GSC点击、GA4用户/会话当IP。
3. 每天上网查看Google官方Ads帮助、Ads/Commerce近期公告和相关开发者文档。只打开与现有Search、关键词/搜索词、地域、RSA/资产、预算止损、转化/归因及线索质量直接相关的更新。记录页面链接、发布日期/更新时间（页面没有则NOT_STATED）、访问日期、对本账户适用性。不要为凑“新技术”编造每日新发现，也不采信未核实的教程和营销承诺。
4. 使用合法且新鲜的脱敏数据，将实际搜索词、花费、正确落地页、真实收到咨询、阿文回应和线索质量串起来。电话/WhatsApp点击不等于真实入站；追踪故障先对账，不把Ads0转化当成0咨询。本轮正常验收排除清单：`logs/handoffs/2026-10-08-owner-direct-preparation/normal-acceptance-exclusions-v35.json`。只在自己的业务报表按匿名ID排除，不改原生统计、不删除记录。
5. 优先检查：无关意图与地区、搜索词匹配、渠道故障/响应延迟、标题与服务页面不一致、低搜索量和出价问题的区别。无需花费的分析/草案继续完成；外部变更按准确对象与版本另行批准，先查否定词与核心业务冲突。
6. 新技术逐项写“立即采用R0方法 / 单变量候选 / 暂不适用 / 等数据”，附理由、成功指标、成本/隐私风险、审批、停止条件和复查日期。不把官方总体平均提升当FLASH CAST效果保证。
7. 真正实施后按同口径比较；样本不足只记方向性信号，不能声称统计显著、CPL降低或ROI提高。每轮固定聊天报告、V2校验和项目内学习事件区分事实、推断、假设。

## 业务指标与决策

- 主指标：可归因的实际开支 / 销售确认有效咨询数；分开列广告费和实际含税/调整后开支。报价率、成交率仅来自脱敏销售真值。分母为0时写无有效咨询及花费，不写CPL=0；分母或归因未知则DATA_MISSING。
- 护栏：总开支上限、无效意图花费、可承接地区、真实收件/接待、重复/验收记录、页面正确与隐私/素材权利。预算是上限，不是必须花完的任务。
- 每日决定优先“减少明显浪费、改善消息匹配、保证接待”而非降CPC。单纯低CPC可能带来低质咨询；只凭点击多/推荐分高不扩预算。
- 当前两系列总广告费各RM1350，合计2700，按8%SST估算含税2916、留84，最终以实际账单为准；10月8–14日、每天10–22，店铺仍10–19不改。V40真实预算保存、V42真实启用；本流程不重复保存预算。预算耗尽或到期不延长、不转移、不恢复。
- 止损方案和签核以当前JSON/CURRENT.md/V38具名值守及V42实际执行回执为准。阿文值守、老板本人FPX安排、唯一负责助理独立验收和精确启用许可已记录；四小时报告不是实时含税自动暂停程序，不新增自动规则。

## 2026-10-09 新增：出价后逐词展示、位置与成本检查

老板要求出价不能定死，必须检查是否真实展示及排名限制。每次日检同时读取 [逐关键词出价与广告位置日检](paid-keyword-bid-and-placement-daily.md)：10:00按实际在投词完整核资格和最近可用竞争窗口，14/18/22复查今日触达、异常及已改价重点词。缺字段如实列未检，不以4小时未更新的份额反复调价。

必须区分当前最高CPC、有效调整和实际CPC；Search IS/top IS、因rank/budget丢失机会、Top/Abs.Top诊断和有效咨询一并判断。每个Sponsored results文字广告分组最多4条，不是整页最多4条；顶部非第一也不能证明第二/第三或排除第四。固定第二/第三只作为争取方向，不承诺；低搜索量不靠加价解决，明确rank损失再提准确单变量候选，不突破原预算及当前出价护栏。

本次仅更新R0方法，不新建/修改自动任务或授权，不覆盖原3词低价候选，不Save或自签QA。修改前准确字节备份：backups/paid-bid-placement-rules-20261009/paid-efficient-daily-learning.before.md；历史冻结文件不改，未来真实日检与账户执行须各自原生证据。
