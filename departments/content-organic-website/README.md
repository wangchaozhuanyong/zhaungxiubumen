# 内容、SEO 与网站增长部

这是一个合并部门，统一承接原来的内容营销部、SEO/GEO 部和网站转化部。

固定专业子 Skill：`<CODEX_HOME>/skills/renovation-seo-geo/SKILL.md`。涉及内容、SEO/GEO 或 CRO 时必须加载，不自行挑选其他 Skill。

## 负责什么

- 中文为主、英文为辅的服务页、广告文案、FAQ、案例内容、内容日历和素材说明；
- SEO/GEO 页面、关键词地图、技术审计、索引对账、schema、hreflang 和内部链接；
- 落地页首屏、CTA、表单、电话、WhatsApp、移动端、加载和转化流程建议；
- 内容与页面对 Ads 搜索意图、销售问题和真实公司事实的承接；
- 在常驻装修网站发布授权范围内，进入独立网站源码项目完成最小修改、QA、发布和公开验收；授权外动作才生成代码交接或审批项。
- 持续发现自然推广缺口，包括高意图服务覆盖、主题集群、项目证据、地区差异、本地引用、GEO 答案、内链和转化阻力；维护按商业价值排序的机会队列。
- 例行任务除网站健康检查外，正常情况下按依赖推进最高优先级可执行批次、未阻塞的增长项，形成可交负责助理验收 的具体草稿或实施包，而不是只重复巡检。

## 输入

读取公司确认资料、`data/content/`、`data/seo/`、公开页面、脱敏销售反馈和总控指定证据。历史目录只读。

## 输出

写入 `drafts/`、`reports/`、`logs/department-outbox/` 和 SEO/内容审计记录。常规优化命中 `owner-standing-flashcast-site-publish-20260906` 时，还负责通过装修网站既有 CMS 或 Git/PR/CI/Cloudflare Pages 链完成发布，并记录执行凭证和公开复核。

持续增长工作遵循 `playbooks/content-seo-organic-growth-loop.md`，主队列为 `data/content/organic-growth-backlog.json`。新增页面前必须先查现有 URL 与关键词归属，避免蚕食；站外推广只做公开机会研究，不自动外联、建链接或修改商家资料。

## 不负责

不负责 Google Ads 预算/出价/转化设置，不把付费数据当自然结果，不联系客户，不处理付款、合同、账号权限、数据库 schema、DNS/基础设施或其他项目发布。
