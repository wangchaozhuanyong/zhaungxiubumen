# 后台发布部

提前跟进网站代码和CMS发布计划，按 [唯一共同发布流程](../../playbooks/department-system-current.md#发布计划与及时接续) 落实批次、依赖及真实结果归回。原指定开发执行代码部署；本部门沿原准确授权执行CMS保存、版本读回与公开核对。跟进不替换原主负责人、原协作职责或原执行者，不继承旧许可。

## 工作窗口和文件归属

后台发布部固定窗口归「装修公司虚拟员工」项目，由总部统一协调。装修官网的发布草稿、网站交付和公开验收文件归原网站仓库 `<WEBSITE_PROJECT_ROOT>`，按原任务复用 `drafts/publishing/` 和 `reports/` 等既有目录。部门任务记录、派送回执、正式结果登记和协调账本仍归部门系统。回传时按现行流程关联网站交付原路径及 SHA256。
