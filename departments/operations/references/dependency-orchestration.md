# 依赖编排接口参考

共同流程只按[唯一正文](../../../playbooks/department-system-current.md)，不另设审批或守候链。一个目标一个原专业主负责人，依赖图明确实际生产部门、先后与准确输入；可独立步骤继续，缺口只阻断依赖项。跨专业由HQ协调，结果回原主负责人。

`dispatch-plan --goal-input`按当前完整合同创建原部门波次；`depends_on`只表达真实业务依赖。部门内并行仅限准确授权的独立无重叠任务并沿既有delegation-check核边界，不自动新增代理或窗口。保持预算、对象、版本、幂等和未知效果检查。实际派送/ACK/实收分别记实；先读真实效果再恢复，不以报告替执行。
