# FLASH CAST 文字系统：建筑杂志式轻注释，中英双语

现行正文规则（老板2026-10-08确认）：六类有字视频共用建筑杂志式轻注释，深炭灰中英双语、轻字重、小信息模块、主题与说明分时，必要时小面积中性浅白半透明衬底。统一设计语言，不复制固定坐标、句子或alpha；历史白字、密集双栏及“禁止一切衬底”只作历史复现，新帧须看原尺寸和手机样张。

## 一套信息，两级语言

- 中文是主信息，英文准确、精简地对应说明，不是装饰。封面、主题、小标签、设计说明、改前/改后、CTA、片尾逐项配对，不能只翻译主标题。
- 中文采用短主题和具体设计安排，英文按意义自然翻译，不堆无意义ALL CAPS或刻意拉长字距。
- 描述中英双语；老板明确保留5个中文话题，英语主题/空间/地区关键词融入英文描述，不另加5个英文标签。
- 明确要求无正文文字的任务仍遵守copy_mode=none；启用的封面和发布描述照常双语。品牌专名不随意改名。

## 字体层级起点（1080×1920）

| 信息 | 真实字体 | 尺寸起点 |
| --- | --- | --- |
| 中文短主题 | STSongti-SC-Regular，常规可读笔画 | 64–72px |
| 英文主题 | AvenirNext-Regular，常规无衬线 | 36–40px |
| 独立中文说明 | PingFangSC-Regular | 46–52px |
| 对应英文说明 | AvenirNext-Regular | 36–40px |
| 必要对照标记 | 苹方 / Avenir | 32px / 28–32px |

中文书刊感标题搭配清晰英文辅助行；不用粗黑展示字、极细笔画、加粗英文或细斜体营造假高级。尺寸只是1080画布起点，360px实际观看能读清优先。长句先精简或分时，不靠无限缩字。设置font-synthesis:none，实检字体加载、缺字和标点。本机渲染，不复制系统字体文件。字体不可用时选已安装的合适真实字体并重新看样张，不静默回退。

## 字色与画面保护

- 默认深炭灰，起点#292e30；英文#363d40，不靠灰到看不清制造层级。优先利用自然浅墙/地面/地毯。
- 先试无底轻注释；复杂纹理或读字不稳时，允许小面积中性浅白真实RGBA衬底与克制细边框。先缩模块面积和信息量，再调透明度；不得把暖米色叠在木纹上反复降低透明度。透明度没有通用合格数值，须按背景实测。
- 禁止整条厚底板、粗色条、无目的长横线、模糊/毛玻璃、重阴影、整图变暗；不降低空间照片清晰度。深色背景可提高局部浅底不透明度，不把“越透明”当目标。
- 先保护家具、柜门、五金与空间关系，再找文字位置：下方自然空地 → 空墙/地毯留白 → 精简、分时或重规划取景；实在无法避让时只触及非关键边缘并留审图证据。不能为了避家具沉到平台描述区，也不裁出大片地板把家具挤远。
- 黑字无法清楚显示时，先换位置、精简或换取景，不默默恢复白字；确需例外说明画面原因。
- 每个阅读节拍只讲一组中英文，中文在上、英语在下；主主题与细节分时出现。对照标签有必要时可同时出现，但不恢复“主标题＋英文＋两组细节”的默认双栏。读图与读字交替，保留完整空间无字观看时间。
- 坐标按镜头实测，不把本次x88/y1298当通用值。封面按[独立规则](approved-cover-design.md)布局，不套正文下沿。

## 共用组件

新片按需引用departments/visual-design-video/assets/typography/light-editorial-bilingual.css，复制到版本assets。用.fc-note、.fc-note--detail、.fc-note--plain；逐镜设置--note-x、--note-y、--note-w、--note-alpha、--note-size。组件只给可调排版，不内置自动播放。

房间照片保持原文件，字幕与框架使用真实可编辑HTML/CSS层。ImageGen用于空间原创和创意探索，不用生成式整图重绘完成最终排版；提示词中的透明度目标不是实测图层alpha。禁止为了改字让家具、窗框或材质细节漂移。

旧ink-editorial-bilingual.css、quiet-brand.css与ivory-open-frame.css只供历史复现；不重写以免改变旧工程。六类共用双语层级和画面保护，不固定同一皮肤、文案、坐标或转场。封面独立设计，不套正文小注释；用户当前选定封面优先。

## 摄影与剪辑配合

- 高级感的顺序是空间、光线、材质、文字、装饰；先让家具关系可读，不能为了放字刻意增加大片地板/天花。既有同视角对比须保留一致裁切，不拉伸画面伪造宽度。
- 先逐镜核曝光、中性区域和材质，再决定是否校色；原图合格可保持。不能以全局泛黄、压暗、发灰、强锐化制造风格。具体方法读full-house-custom-ad的filter-color-system.md。
- 全景说明布局，真实相关细节说明工艺，再回到全景；裁切细节须注明是同源裁切，不冒充新机位。音乐乐句与阅读时间决定切点，主图不做Ken Burns；转场读transition-language.md。

## 信息密度与对照阅读（2026-10-08批准）

- 按“短主题”和“设计说明”分档设置模块宽度、字体比例与内边距；同档保持对齐，长说明先改写，不把每句话都塞进同宽大矩形，也不逐字随意跳宽。共用组件提供可选紧凑/说明修饰类，参数仍按画面实测。
- 一条片先归纳少数主信息，重复说明合并，穿插真正无正文文字的完整空间观看时间。本次客厅返工采用三个重点；不是六类视频都必须三点、同样时长或相同句子。
- 讲可见柜体、抽屉、材质时优先保留全景并用[同图局部放大窗](same-image-detail-lens.md)展示对应原位置；这是老板最新认可的细节方式，覆盖旧“独立近景优先”。低清时减小放大窗、限制倍率或换更清晰同源素材，不直接删掉讲解所需细节，也不擅自用另一张生成特写替代。同屏文字和放大窗分区避让，留出干净全景观看时间。
- 同机位对照必须保持相同裁切。双语改前/改后标记要留足稳定阅读时间，不把淡入淡出或快速wipe计作完整阅读；可从约2–3秒试起，按实际字量、音乐和360px样张调整。对照期间避免叠加密集正文。
- 适合的改造片更早展示改后变化，再解释原因；空间展示与读字节拍交替。不能为追求均匀节奏强行把每镜字幕等分，也不以无目的推拉替代观看停留。
- 老板选定的封面、音乐、调色或构图在局部字幕返工中保持不变，除非本轮明确授权调整。计划、当前批次快照、最终解码需一致。

## 制作与校验

1. 全部双语文字完整规划后一次整包轻抖检测，含字幕、封面、口播（如有）、描述与5话题。新增英语使旧单语证据失效。
2. 无命中且实际截图/文字哈希一致直接继续，不询问老板是否看过截图。按[发布包规则](douyin-publish-package.md)执行。
3. 根据中英阅读量定时长；先删冗余，不为双语盲目加图或超过30秒。
4. 常规可从0.24秒淡入、0.18秒淡出起试；淡入淡出不算完整阅读时间。no Ken Burns，图片稳定，仅有目的的局部运动。
5. 原尺寸及360px预览逐镜看字形、英文孤词换行、层级、对比、家具遮挡、上下边界；封面另看3:4与180px缩图。
6. 原生lint/validate/inspect、快照和最终MP4解码分别留证；读取实际对比度，退出码0不等于可读性通过。模板检测未识别新类时记录限制并补实测，禁止加隐藏假字幕或投影骗过规则。
7. 不显示“概念改造演示”“仅设计效果图”“AI设计”或同义制作说明；内部来源与授权保留，不写成真实完工。
