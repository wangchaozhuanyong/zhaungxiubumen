# FLASH CAST 正文文字设计系统

老板于 2026-10-07 明确采用 `typography-design-v2-20261007` 的推荐 A。此选择作为有文字装修视频**正文**的默认设计方向：轻字重、短主题、清楚的设计说明、充足留白。根据每个空间适配，不固定套用卧室坐标、口号或两栏。封面已另选浅色宋体开口细框，读取 [已确认封面设计](approved-cover-design.md)，不要用正文苹方或下方坐标覆盖封面选择。

采用依据：`drafts/creative/fc-20261006-italian-minimal-design-plan-preview-v1/typography-design-v2-20261007/` 中的 A 实景样张与本固定聊天“按照你的推荐，然后帮我skill整理完整”。B 仅保留历史备选。采用设计不等于新文字已轻抖检测或旧 MP4 已返工。

## 字体与信息层级

| 层级 | 默认起点（1080×1920） | 作用 |
| --- | --- | --- |
| 空间标签 | 苹方 Regular 400，26px，字距 6px | 标明空间，视觉从属 |
| 短主题 | 苹方 Light 300，84px，字距 8px | 表达一个设计重点，通常 4–6 个汉字 |
| 设计说明 | 苹方 Regular 400，36px，字距 2px，行距 1.6 | 解释具体安排，通常一至两行 |

用实际可加载的 `PingFangSC-Light` 与 `PingFangSC-Regular`。不靠浏览器把 Regular 合成假细体；设置 `font-synthesis:none`。本机不能加载时，自主选用环境中已有且适用的真实 Light/Regular 字体并校准代表帧，不默默换为粗黑或大宋体。系统字体用于本机渲染，素材包不复制系统字体文件。

字号是设计起点。主要说明在 360px 宽手机预览中应清楚可读，36px 原尺寸对应约 12px；标签只做辅助。主题太长时先精简或改组，再调整字号；不得为了塞进固定横栏把关键解释缩成小注脚。

“静享日常／休息与收纳／各有位置”仅属于卧室示例。客厅、玄关、餐厨、卫浴等按实际设计内容写短主题和说明。方案讲解必须给出具体设计判断，主题不能替代信息。

## 逐图放置与颜色

1. 先看真实图，标出家具、柜门、五金、材料和动线等需要完整观看的区域。
2. 优先选择下方空地；其次选择空墙或画面自然留白。文字与底部平台叠加区的冲突也要一起判断，不机械搬用 `y=1338`。
3. 留白够宽时用主题在左、说明在右；留白窄时改为主题在上、说明在下；构图需要右对齐或中轴时独立调整。位置由每张图决定。
4. 木色/中暗区域优先暖白 `#fffaf1`；浅色区域可用深墨 `#28231e`。保留同一字体层级和布局逻辑，字色服从实际对比。
5. 正文对比不足时，仅在文字所在的空地使用轻量渐层；不盖家具、不加厚灰板、不用整片变暗来让白字可读。明亮图可直接改用深墨。这不是封面许可：已确认封面禁止衬底/阴影，按封面模块解决对比；用户当前要求全部无阴影时正文也遵守。

细线仅在分隔主题与说明确实有作用时使用；可取消。不开启装饰英文、随机横线、粗描边、重投影或逐字花哨特效。用户要求无字时，沿用 `visual_music/copy_mode=none`，不因本模块添加文字。

可复用实现：`departments/visual-design-video/assets/typography/quiet-brand.css`。制作时复制到当前工程 `assets/`，用相对路径引入。组件中的卧室位置只是样例默认值；每镜显式设置 `--fc-copy-left`、`--fc-copy-top`、`--fc-copy-width` 和必要的字号/字色。主体照片保持稳定。

最小结构（放在本镜头的信息层中，文字须来自本批定稿）：

```html
<link rel="stylesheet" href="assets/quiet-brand.css">
<div class="fc-quiet-copy"
     style="--fc-copy-left:108px;--fc-copy-top:1338px;--fc-copy-width:862px">
  <p class="fc-quiet-label">卧室设计</p>
  <div class="fc-quiet-row">
    <h2 class="fc-quiet-title">静享日常</h2>
    <div class="fc-quiet-detail">
      <p>休息与收纳</p><p>各有位置</p>
    </div>
  </div>
</div>
```

窄留白使用 `fc-quiet-copy is-stacked`，不需要分隔线时使用 `no-divider`。轻渐层为单独的 `fc-quiet-veil`，按真实对比决定是否启用，不成为每镜常驻滤镜。多镜头按 HyperFrames 合同分别登记时间，不将本段结构直接当完整时间线。

## 克制入场与阅读时间

推荐一组文字约 0.3 秒淡入，说明比主题晚约 0.06 秒，离场约 0.18 秒淡出；只在音乐和文字阅读需要时调整。根据说明长度留足阅读时间，常见短组至少约 2.5 秒，不将这个时长套为所有镜头的硬门。

入场以 opacity 为主；必要时信息层轻移不超过约 6px。所有文字动画登记到同一个 HyperFrames GSAP 暂停时间线，保持可 seek。图片背景不随文字一起位移。静态 CSS 组件不包含自动入场动画，需要当前工程结合镜头时间实施。

## 接入现有制作流程

- 先完成空间覆盖、音乐和镜头职责，再规划每镜主题/说明及其位置。
- 将字体、字色、位置、所保护的家具和入场时机记在当前 `DESIGN.md` 或 storyboard 的创意说明中；不新建另一份平行生产合同。
- 正式封面读取独立的 [已确认封面设计](approved-cover-design.md)：宋体主标题和开口细框，与正文共享克制审美但不共享字体/坐标。按3:4与9:16同构适配，卧室正片位置不直接用于封面。
- 全部字幕、封面文字、口播、描述与正好 5 个话题先定稿，再按 `douyin-publish-package.md` 整包真实轻抖检测。改变主题或说明时旧结果不继承；仅改字体/位置且文字不变时保留同版检测证据。
- 制作任务按老板当前直接成片偏好，由设计部完成代表帧内检后继续制作，不再重复询问已批准的字体方向；当前任务明确要求先看图时再按其顺序交代表帧。

## 验证重点

检查实际字体加载、字符正确、主题与解释层级、自然换行、对比度和边界；查看每镜原尺寸和 360px 手机预览，确认家具与重要工艺完整。HyperFrames lint/validate/inspect 与实际快照用于检查工程，实际 MP4 解码用于最终画面和动效验收。样例通过不替代新镜头检查。

当前采用版与验证：A 已有 1080×1920、局部及手机预览；3 个字体面在原样张加载，validate/inspect 无错误。本模块只复用实际使用的 Light 与 Regular 两个字体面。后续成片按当批真实输出验证。
