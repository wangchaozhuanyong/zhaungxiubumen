# 自主装修创意工作流

先执行 [项目叠加规则](adaptive-renovation-workflow.md)，通用状态机只有 `$full-house-custom-ad/references/adaptive-production-core.md`。本文件只负责自主创意判断；六类的现行文字、封面、同图细节及直接交付以本部门主Skill引用为准，不沿用旧无英文/强制角标偏好。

本流程让老板只给业务目标也能开始，但不把“自主”误解为“自动写文案”。输入来源和视频呈现是两个独立决策。

## 一句话任务合同

下面的输入已经足够：

```text
做一条装修空间展示视频，参考这个节奏，直接制作内部候选，不发布。
```

设计部可自主选择比例、时长、镜头节奏和候选音乐，并记录假设。只有以下情况阻塞：

- 要宣称真实案例、价格、工期、资质、评价或客户结果，但没有证据；
- 要使用来源不明或未授权的客户素材、字体、人物或第三方作品；本项目已验证库内音乐按现行全库制作使用决定，不逐首确认；
- 要做真实连续漫游，但没有连续视频来源或合适能力；
- 需要登录、付费、上传、发布、投放或联系客户，但没有单独批准。

## 第一步：判断 `input_mode`

- `coordinated_campaign`：已有广告或内容 brief；
- `autonomous_direct`：只有一句目标；
- `reference_driven`：有视频、截图、分享文案或链接；
- `asset_driven`：有真实授权素材。

输入模式只说明“从哪里开始”，不决定视频里是否有文字。

## 第二步：先判断 `presentation_mode`

必须在生成任何文案之前完成。

### `visual_music`

适用：用户明确要求无字或纯欣赏的空间、案例氛围、连续看房、材质细节短片。常规六类任务仍提供必要简洁双语说明，不能仅凭“空间展示”或参考片少字就自动删正文。

- 默认 `copy_mode=none`；
- 不生成主标题、AI 口号、英文副标题、字幕或叙事 CTA；
- 首 3 秒靠画面入口、空间揭示、运动方向和音乐建立停留；
- 获客信息放发布说明、独立封面或另做 `minimal_brand` 版本，不污染主片。

### `minimal_brand`

适用：确实需要品牌识别、AI 概念披露、项目身份或用户明确要求的短尾帧。

- 只保留必要文字；
- 每项文字记录用途与停留时长；
- 可见文字必须有准确配对英文，不加装饰性英语；
- 不把品牌尾帧扩写成广告脚本。

### `copy_led`

适用：避坑知识、流程解释、报价逻辑、工艺对比、口播、明确促销或广告主张。

- 才需要目标客户、心理按钮、文字钩子、脚本、字幕和 CTA；
- 公开文字先完整中英规划、真实整包轻抖并内检；独立QA与任何外部发布按原任务/总控权限，不自行向内容部插话；
- 六类有字任务均采用正文统一双语，不因本次未重复说“英文”删掉已确认辅助语言。

## 默认判断规则

按以下优先级选择：

1. 用户明确说“无文案/不要字/只看空间/跟音乐走” → `visual_music`；
2. 用户明确要求复用参考片的无字呈现 → `visual_music`；仅参考节奏、构图不改变当前文字要求；
3. 任务需要解释事实或行动步骤 → `copy_led`；
4. 只需要轻品牌或披露 → `minimal_brand`；
5. 常规六类视频按实际信息任务做必要的简洁双语说明；只有明确纯欣赏/无字需求才默认 `visual_music`，不用旧无字样片覆盖老板最新偏好。

## 自主候选不再只比文案

`visual_music` 的 3–5 个候选应改变以下一项主变量：

- 音乐与情绪；
- 空间进入顺序；
- 连续源镜头的观看顺序，或静态图的局部揭示、同图放大与静止留白；不对整张静态空间图持续推拉/横移；
- 画面冷暖、对比、材质强调；
- 长镜头与切镜密度；
- 开场的空间信息量和第一处高潮位置。

评分维度：首 3 秒视觉停留、空间可读性、音乐贴合、镜头可执行性、真实性风险、素材可得性和目标适配。无字路线不设“钩子文案”门槛。

`copy_led` 才按前 5 秒文案、信息清晰度、事实安全和 CTA 评分。

## 参考驱动

1. 用 `scripts/reference_media.py fetch` 将分享文案/URL 冻结为本地可播放文件；本地视频直接用 `analyze`。
2. 生成 ffprobe、contact sheet 和可选参考音轨。
3. 人工拆解视频类型、首尾一秒、机位、空间路径、单镜时长、切镜结构、调色、文字密度和音乐结构。
4. 写清“保留的语法”和“必须原创的内容”。
5. 禁止复制原素材、空间、文案、品牌、水印、音乐文件或完整镜头顺序。

参考视频没有本地可播放正文、ffprobe 和关键帧证据时，不得声称已经分析。

## 音乐先行

`visual_music` 固定顺序：

`选歌候选 → 校验授权边界 → 实际音频分析 → music-map → visual-sequence → 分镜 → 渲染挂载 → 成片听检/ffprobe`

音乐库工具只推荐，不会自动修改项目。`music-selection.json` 必须记录：曲目、来源、授权状态、目标渠道和推荐理由。`music-map.json` 必须记录：时长、BPM 估算、前奏、首个清晰落点、能量段、高潮、结尾和人工听检结论。

不要追每一个鼓点。空间展示通常让一个镜头跨 4–8 拍，只在乐句、能量或空间结构变化处切镜。

## 真实性等级

- 静态 AI/效果图运动通常是 L1；
- 多段独立 AI clip 通常是 L2；
- 真实连续拍摄或经过验证的连续生成视频才可能是 L3/L4；
- 工具包装、转场或音乐不能升级真实性。

内部资产台账如实记录概念来源，画面默认无制作角标、描述只讲设计。当前任务确有必要的披露另按项目叠加规则；平台生成内容标记由老板处理，不擅自记为完成。

## `creative-strategy.md` 必填

- `input_mode`；
- `presentation_mode` 与 `copy_mode`；
- 用户目标、地区、素材时间范围、成功指标和直接制作授权；
- 使用的事实、参考、素材和学习记录；
- 候选方向、评分、淘汰理由和选中方案；
- 音乐来源、授权状态和参考分析状态；
- 真实性标签；
- 只有 `copy_led` 才填写主客户、心理按钮、钩子和 `copy_status`；
- 风险、待校准项和外部动作审批边界。

## 跨部门交接

- `visual_music/copy_mode=none`：不因“缺正式文案”自动找内容部补文案；内容部只复核发布说明、必要披露或元数据。
- `copy_led`：公开文案完整定稿、轻抖与内检；已派任务需要内容/固定QA复核时由总控按准确包安排，不默认跨任务发消息。
- 渠道、受众、历史表现或测试指标是假设时，交 `paid-growth-data` 验证。
- 事实、版权、真实性、音乐四态和发布前检查交 `qa`。

## 完成标准

成片不只是一份 MP4。至少包含：策略、素材来源、音乐选择与结构、视觉分镜、生产合同、技术 QC、关键帧/contact sheet、真实性标签、音乐四态、QA/HOLD 状态和学习记录。未获 Reality Checker PASS 时只能称内部候选。
