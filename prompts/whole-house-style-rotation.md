# 全屋定制风格轮换

自动原创且用户未指定风格时，按以下顺序取下一种：

`现代简约 → 法式奶油 → 工业质感 → Japandi → 现代经典 → 南洋热带现代 → 意式极简 → 现代农舍 → 现代东方 → Art Deco → 北欧明亮 → 度假巴厘 → 意式轻奢 → 中古现代 → 海岸地中海 → 侘寂自然 → 新古典 → 都市 Loft → 原木无印 → 过渡风格 → 现代轻奢 → 新中式 → 法式经典 → 美式现代`

第一轮用每种风格的 `V1`，第二轮 `V2`，第三轮 `V3`；72 个组合完成前不回到第一组。

判定“换了风格”时，至少同时更改柜门、材质、配色、五金、灯光、空间节奏中的 5 项；只换滤镜或墙色无效。

用户点名风格优先，但不自动消耗顺序；真实项目按现场与客户 brief，不强行套轮换。
